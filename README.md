python_voice_assistant-

A modular and lightweight desktop voice assistant written in Python. It converts user speech to text, interprets spoken commands, and performs automated actions while delivering voice feedback in real time.

 ✨ Features
* Speech-to-Text Integration: Accurately listens and transcribes user voice inputs.
* Text-to-Speech Output: Provides natural, spoken responses to user queries.
* Task Automation:Performs automated tasks such as answering queries, system controls, and web interaction.
* Modular Codebase: Easy to extend with new custom commands and APIs.
